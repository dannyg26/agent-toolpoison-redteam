## Evidence gathered (all offline, no model, no cloud)

- **Offline suite:** `python3 -m unittest test_v2` in WSL gave **19 tests, OK, 1.3 s**. The suite does not
  cover: NUL or surrogate characters in commands, how non-ASCII output grows under `json.dumps`, the
  launcher's `finally` path, the v2_pod.sh timeout fallback, freeze coverage, or dev-task prompts.
- **Environment check** (`/home/capstone-study/stage_e/v2_environment_check.{json,log}`):
  - Run 1 (17:40, one probe per task): `all_ok: false`. `2017q-pwn-pilot` and `2018q-pwn-get_it` were
    `target_reachable: false`, even though `wait_healthy()` had just passed for both.
  - Run 2 (17:46, modified script with up to 3 probes): `ALL OK`. `2018q-pwn-bigboy` and
    `2023q-pwn-unlimited_subway` each needed **2 attempts**.
  - So 4 different tasks failed their first fresh connection across the two runs. This is an intermittent
    transient, not a fixed per-task fault. All ELF starters were `X` (executable) in both runs.
- **Stage C speeds** (ctf20261119c traces, 281 requests, concurrency 1):
  - Generation: median 208 completion tokens and 5.9 s per request; mean 576 tokens and 14.3 s; max 99 s;
    about 37.5 tok/s.
  - Terminal calls: mean 1.03 s; 3 of 364 timed out.
  - Prompt tokens: median 5,236; max 30,912.
  - finish_reason: `tool_calls` 278 times, `length` without a call 3 times.
  - Stage C endings: context_budget 7 of 28, time_budget 10 of 28.
- **Probes of pure functions** (scratch script, no sandboxes):
  - `display_safe` of 32 KB random bytes shows 8,228 characters, which is 9,823 after `json.dumps`.
  - 8 K characters of valid non-ASCII text (e.g. C1 controls or CJK decoded from binary) shows 8,226
    characters, which becomes **49,202** after `json.dumps` (larger than the 48,000 tool-text limit). C1
    controls are kept.
  - `environment.command(['bash','-c','echo a\x00b'])` raises `ValueError: embedded null byte`. A command
    containing `\ud800` raises `UnicodeEncodeError`.
  - `analyze_v2` with one primary arm missing reports the remaining contrast with raw p only (no Holm).
- **WSL host:** 8 vCPU, 7 GB RAM (about 6 GB available), 2 GB swap.

## Must fix before freeze

1. **R2-01**: find the reachability root cause; add a settle step to `EnvironmentV2` used by both the
   check and the trials; re-run the check; record attempts in traces.
2. **R2-02**: make log fetching unable to block `terminate()`.
3. **R2-03**: decide the wall cap versus the count-budget claim. Pre-register the time_cap share and a
   sensitivity analysis. Recompute cost (R2-28).
4. **R2-04**: return NUL or unencodable commands as invalid tool calls, not infra failures.
5. **R2-05** (+ R2-21): `ensure_ascii=False`; token-aware (or tighter, assistant-inclusive) elision;
   C1/bidi display rule.
6. **R2-06**: freeze the vendor asset hashes and the image-to-Dockerfile link; require a passing, hashed
   `v2_environment_check.json`; make all private files mandatory.
7. **R2-07**: decide the arm order (aligned first recommended), or pre-register the missing-control case.
8. **R2-08**: dev gate limited to transport and sandbox health; pre-register what happens when it fails
   because of model behaviour.
9. **R2-09**: v2_pod.sh fallback only on process death; kill the first server before any fallback.
10. Small text and code items: **R2-13** (token-cap guard), **R2-15** (Holm rule), **R2-16** (merge and
    validation), **R2-17** (seed caveat), **R2-18** (soft-stop reserve), **R2-19** (check `all_ok` and dev
    tasks), **R2-20** (stale design doc and config status), plus the limitations text for **R2-10**.

Strongly recommended, and free: **R2-11** (3-concurrent no-model soak on this 7 GB WSL host) before
spending.

## Top 5

1. **R2-01**: first-connection reachability fails intermittently (4 tasks across 2 runs), and nothing in
   the trial path protects against it.
2. **R2-03**: the 900 s cap will probably bind before the count budgets (about 765 s projected for 50
   steps at concurrency 1, more at concurrency 3), so the "counts are primary" design does not hold as
   written.
3. **R2-02**: an unguarded log fetch in `finally` can skip pod termination (cost safety regression from
   stage C).
4. **R2-05**: elision does not track the real context. JSON escaping lets one display grow to about 49 K
   characters, assistant text is uncounted, and the prompt + 4,096 limit applies, so context_budget
   endings will continue.
5. **R2-06 / R2-07**: the freeze does not cover the task files or the environment check, and the control
   arm is scheduled last.
